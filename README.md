# Portfolio — Abibou Ndione

Portfolio personnel de développeur web et mobile.

**Site en ligne : [abibou-ndione-portfolio.vercel.app](https://abibou-ndione-portfolio.vercel.app)**

## Technologies

- [React 19](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- [Vite 8](https://vite.dev)
- [Tailwind CSS 4](https://tailwindcss.com)
- [Motion](https://motion.dev) pour les animations
- [shadcn/ui](https://ui.shadcn.com), [Lucide](https://lucide.dev) et [Sonner](https://sonner.emilkowal.ski)

## Déploiement

Le projet se déploie tel quel sur [Vercel](https://vercel.com) (détection automatique de Vite) : importer le dépôt GitHub, aucune configuration n'est nécessaire.

## Lancer le projet en local

Prérequis : Node.js et npm.

```sh
git clone https://github.com/Bibalaye7/abibou-ndione-portfolio.git
cd abibou-ndione-portfolio
npm install
npm run dev
```

Le site est alors disponible sur http://localhost:8080/.

## Build de production

```sh
npm run build
npm run preview
```
